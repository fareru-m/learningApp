# 基本情報技術者試験学習支援ウェブアプリケーション

このプロジェクトは、日本の基本情報技術者試験の対策を支援するための包括的なウェブアプリケーションです。CBT（Computer Based Testing）形式に完全対応し、多様な学習ニーズに応える機能を提供します。

## アプリケーション概要

### 主要機能

本アプリケーションは以下の主要機能で構成されています：

- **クイッククイズモード**: 10問のランダム出題による効率的な知識確認機能
- **カテゴリ別練習モード**: テクノロジ、マネジメント、ストラテジ分野別の重点学習機能
- **模擬試験モード**: 実際の試験環境をシミュレートする本番形式の演習機能
- **専門用語学習機能**: IT関連の重要用語を体系的に学習する機能
- **試験情報提供機能**: 最新の試験制度やスケジュール情報の提供
- **学習進捗管理機能**: 学習履歴の記録と成績の可視化機能

## ユーザーインターフェース

### メインメニュー構成

アプリケーション起動後に表示されるメインメニューでは、以下の機能を選択できます：

- **クイッククイズ**: 短時間での知識確認を目的とした10問ランダム出題モード
- **カテゴリ別練習**: 特定分野の重点学習を行う分野別練習モード
- **模擬試験**: 実際の試験形式で本番体験を行うシミュレーションモード
- **専門用語暗記**: IT用語の意味を学習する語学学習モード
- **試験情報**: 試験に関する最新情報やスケジュールを確認
- **学習進捗**: 個人の学習履歴と成績推移を確認
- **背景音楽**: 学習集中を高めるBGM再生機能
- **設定**: アプリケーションの各種設定を行う

## 学習モード詳細

### 1. クイッククイズモード

**目的**: 短時間での効率的な知識定着と理解度確認

**仕様**:
- 問題数: 10問（questions.jsonからランダム選択）
- 出題形式: 4択問題
- 制限時間: 設定なし（自己ペース）

**機能特徴**:
- 即時フィードバック機能（解答選択後に0.5秒間のポップアップ表示）
- 双方向ナビゲーション機能（前の問題・次の問題への移動）
- 解答履歴の自動保存と再表示機能
- 正解・不正解の視覚的識別（色分け表示）

**操作手順**:
1. 解答選択肢をクリック
2. 自動的にフィードバックが表示
3. 「←前へ」または「次へ→」ボタンで問題間移動
4. 全問題終了後に「採点」ボタンで結果確認

**解答再表示機能**:
- 既解答の問題に戻った場合、ユーザーの解答と正解を色分け表示
- 正解の場合: ユーザー選択を緑色で表示
- 不正解の場合: ユーザー選択を赤色、正解を緑色で表示

### 2. カテゴリ別練習モード

**目的**: 特定分野の重点的・体系的学習

**分類体系**:
- **テクノロジ分野**: ハードウェア、ソフトウェア、ネットワーク、データベース等
- **マネジメント分野**: プロジェクト管理、サービスマネジメント、システム監査等
- **ストラテジ分野**: 経営戦略、システム企画、業務改善等

**機能特徴**:
- 解答の変更が可能（制限なし）
- ユーザー選択肢の青色表示
- 正解の緑色表示による即時確認
- 無制限の練習が可能

**データソース**:
- 過去問題データベース（kakomon_questionsA.json, kakomon_questionsS.json）
- 解答データ（kakomon_answers.json）

### 3. 模擬試験モード

**目的**: 実際の試験環境での実践的演習と本番体験

**試験環境**:
- 試験時間: 実際の試験と同等の時間設定
- 問題数: 実際の試験形式に準拠
- 出題範囲: 全分野から均等な配分で出題

**機能特徴**:
- 解答の変更が可能（試験終了まで）
- 即時フィードバックなし（試験中は結果非表示）
- 完全なナビゲーション機能（全問題への自由移動）
- 試験終了後の詳細な成績分析

**画面構成**:
- 左側パネル: 問題一覧と解答状況のナビゲーション
- 中央エリア: 問題文の表示
- 右側エリア: 解答選択肢の表示

**成績表示内容**:
- 総合スコアと正答率
- 分野別成績分析
- 全問題の解答状況と正解の比較
## 学習コンテンツ

### 専門用語学習機能

**目的**: IT分野の重要用語の体系的な学習と定着

**機能内容**:
- IT関連の重要用語と意味の体系的な整理
- 用語検索機能（部分一致検索対応）
- カテゴリ別表示による分類学習
- 暗記カード形式での効率的学習

**データ形式**:
- JSON形式の構造化用語データベース
- 用語、意味、カテゴリ情報を包含
- 検索機能と表示機能の最適化

### 試験情報提供機能

**目的**: 最新の試験制度・スケジュール情報の timely 提供

**情報カテゴリ**:
- **公式発表**: IPAからの公式な試験関連情報
- **手続き情報**: 申込方法、受験手続き、必要書類等
- **学習アドバイス**: 効率的な学習方法と対策

**更新方法**:
- `examUpdateEntries`配列への新しい情報の追加
- 自動的な日付順ソート機能
- カテゴリ別フィルタリング機能

## ユーザーエクスペリエンス設計

### フィードバックシステム

各学習モードにおけるフィードバック提供方式の最適化：

- **クイッククイズモード**: ポップアップ表示による即時フィードバック（表示時間0.5秒）
- **カテゴリ別練習モード**: サイレントフィードバック（色分けによる視覚的確認）
- **模擬試験モード**: サイレントフィードバック（試験中の結果非表示）

### 色分け表示ルール

視覚的な識別性を高めるための統一された色分け体系：

- **緑色**: 正解を示す
- **赤色**: 不正解のユーザー選択を示す
- **青色**: ユーザー選択（カテゴリ別練習・模擬試験モード）

### ナビゲーション機能

直感的な操作を実現するナビゲーション設計：

- **前へ・次へボタン**: 問題間のスムーズな移動
- **左側ナビゲーションパネル**: 全問題の一覧表示と解答状況の確認
- **自動ボタン状態制御**: 最初・最終問題でのボタングレーアウト機能

## 技術仕様

### フロントエンド技術

**開発環境**:
- **言語**: HTML5、CSS3、JavaScript (ES6+)
- **スタイリングフレームワーク**: Tailwind CSS
- **アーキテクチャ**: シングルページアプリケーション (SPA)
- **状態管理**: JavaScriptオブジェクトベースのクライアントサイド管理

### データ構造設計

**問題データ形式**:
```javascript
{
  "question": "問題文",
  "options": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answer": "正解",
  "explanation": "解説文",
  "category": "分類"
}
```

**ユーザー解答データ形式**:
```javascript
{
  "selected": "ユーザーの選択",
  "correct": "正解",
  "isCorrect": true/false,
  "explanation": "解説"
}
```

## 利用方法

### ローカル環境での実行

**手順1: リポジトリのクローン**
```bash
git clone <repository-url>
cd learningApp
```

**手順2: ローカルサーバーの起動**
```bash
# Python 3を使用する場合
cd frontend
python -m http.server 8000

# Node.jsを使用する場合
npx serve frontend -p 8000
```

**手順3: ブラウザでのアクセス**
```
http://localhost:8000
```

### 学習プロセス

1. **学習モードの選択**: 学習目的に応じたモードを選択
2. **問題解答**: 選択肢をクリックして解答を入力
3. **フィードバック確認**: 即時フィードバックを確認して理解を深める
4. **問題間移動**: ナビゲーション機能を利用して次の問題へ進む
5. **成績確認**: 全問題終了後に詳細な成績分析を確認
