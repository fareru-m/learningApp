# 基本情報技術者試験学習支援ウェブアプリ

このプロジェクトは、日本の基本情報技術者試験の対策を支援するためのインタラクティブなウェブアプリケーションを構築することを目的としています。

## アプリケーションの主なフロー

1.  **セッション選択画面**: アプリケーションを開くと、まず学習の焦点を選択するための画面が表示されます。
    *   **科目A試験**: 多岐にわたる知識分野からの多肢選択問題です。
    *   **科目B試験**: より長く、深い内容のケーススタディ問題です。
2.  **メインメニュー**: セッションを選択した後、ユーザーは選択したセッションに関連する機能が表示されるメインメニューにリダイレクトされます。

## アプリケーションの構成要素

### 1. 主要コンテンツ：過去問バンク

これはアプリケーションの基盤であり、包括的な問題ライブラリとして機能します。
*   **セッション分類**: 問題は、フォーマットと範囲が異なるため、**科目A**と**科目B**で明確に区別されます。
*   **構成（科目A向け）**: 問題は**分野**（テクノロジ、マネジメント、ストラテジ）ごとにグループ化され、さらに**章**（ネットワーク、データベース、セキュリティなど）に細分化されます。
*   **内容**: 各問題には、質問、4つの選択肢、正解、詳細な解説が含まれます。

### 2. ユーザー機能（科目A試験向け）

過去問バンクのデータを利用したインタラクティブな機能：

*   **練習モード**
    *   **目的**: プレッシャーなく学習できる柔軟性を提供し、章ごとの内容理解に焦点を当てます。
    *   **フロー**: ユーザーは分野を選択し、次に練習したい特定の章を選択します。その章の問題が一つずつ表示されます。
    *   **即時フィードバック**: 回答を選択して「チェック」ボタンを押すと、システムは正解（緑）と選択した不正解（赤）を即座にマークし、詳細な解説をその下に表示します。
    *   **ポモドーロタイマー**: 学習セッションを管理するために、オプションでポモドーロタイマー（例：25分集中、5分休憩）を有効にできます。

*   **模擬試験モード**
    *   **目的**: 実際の試験の条件、時間的プレッシャー、フォーマットをシミュレートして、準備状況を測定します。
    *   **フロー**: ユーザーが試験セッションを開始すると、システムは自動的に、実際の試験の比率に合わせてすべての分野と章からランダムに選ばれた問題セット（例：80問）を提示します。試験タイマー（例：150分）が作動します。
    *   **試験中**: 即時のフィードバックはありません。ユーザーは、試験を終了する前に見直したい疑問のある問題にマークを付けることができます。
    *   **結果ページ**: 試験終了後、要約ページが表示されます。内容は次のとおりです：
        *   合計スコアと正答率。
        *   スコア基準に基づく合否ステータス（合格/不合格）。
        *   すべての問題、選択した回答、正解のリスト。これにより、ユーザーは間違いを見直すことができます。

### 3. サポート機能

*   **音楽プレーヤー（YouTube経由）**
    *   **目的**: 学習中の集中力を高めるためのBGMを提供します。
    *   **表示**: 開閉可能なサイドタブ（サイドパネル）があります。
    *   **機能**: パネル内には次のものがあります：
        *   YouTubeで音楽ビデオを検索するための**検索バー**（例：「lofi hip hop radio」）。
        *   選択したビデオを再生するための**プレーヤー**。

## 技術スタック

*   **フロントエンド（クライアントサイド）**:
    *   **フレームワーク**: **React** または **Vue.js**。どちらも動的でインタラクティブなユーザーインターフェースの構築に非常に優れています。
    *   **スタイリング**: 通常のCSS、SASS、またはTailwind CSSのようなフレームワーク。

*   **バックエンド（サーバーサイド）**:
    *   **ランタイム**: **Node.js**。
    *   **フレームワーク**: **Express.js**。軽量で高速であり、Node.jsでAPIを構築するためのデファクトスタンダードです。

*   **データベース**:
    *   **タイプ**: **SQLite**。ユーザーデータがないため、SQLiteのようなシンプルなデータベースで問題を保存するには十分です。
